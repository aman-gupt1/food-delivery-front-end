# 🍔 Food Delivery Website

A responsive and modern Food Delivery Website built using **HTML, CSS, and JavaScript**.

---

## 👨‍💻 About Project

This project is a frontend-based food delivery website designed to provide users with an interactive and user-friendly food ordering experience.

The website includes food product listings, responsive design, dynamic product handling using JSON data, and modern UI components.

---

## 🎯 Purpose

This project was created for self-improvement and to strengthen frontend development skills by building a real-world food delivery website interface using HTML, CSS, and JavaScript.

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* JSON

---

## ✨ Features

* Responsive Design
* Dynamic Product Display
* Modern UI/UX
* Food Menu Section
* Interactive Components
* Mobile Friendly Layout
* Cart Management
